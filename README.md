JavaCoreSandBox — это база знаний и песочница, содержащая примеры кода и выполненные задачи по модулю Java Core.
Проект предназначен для закрепления теории, рефакторинга кода и подготовки к техническим собеседованиям.

Репозиторий демонстрирует эволюцию навыков написания чистого кода и понимания базовых принципов Java.
Стек технологий Язык: Java (Core, фичи версий 17/21).
Сборка: Maven или Gradle.
Тестирование: JUnit 5 и Mockito.3. 

В репозитории собраны примеры и задачи по следующим блокам:
 - Устройство JVM, память (stack/heap), примитивы и ссылочные типы.
 - Принципы ООП, SOLID, интерфейсы и абстрактные классы.
 - Исключения и Generics.
 - Коллекции (внутреннее устройство ArrayList, HashMap и т.д.), итераторы и Big-O.
 - Лямбда-выражения, Stream API и Optional.
 - Многопоточность (потокобезопасность, ExecutorService, Atomic и синхронизация).
 - Ввод/вывод (I/O, NIO), рефлексия и сериализация.
